# Task 2: Phishing Awareness Training

Part of the **CodeAlpha Cyber Security Internship** (November 2026).

## Description
A short training module that teaches how to recognize and avoid phishing attacks:
- Types of phishing (email, spear phishing, whaling, smishing, vishing, quishing)
- How to spot a phishing email (annotated example)
- How to spot a fake website (look-alike domains)
- Social engineering tactics used by attackers
- Real-world examples and the lessons learned
- Best practices and what to do after clicking a malicious link
- An interactive quiz

## Interactive quiz
Download the repository (or just `quiz.html`) and double-click `quiz.html`.
It gives instant feedback with an explanation for each of the 8 questions and a final score.

## Key takeaways
- Check the sender address and hover over links before clicking.
- Urgency, fear and authority are the main pressure tactics.
- A padlock (HTTPS) does not prove a site is trustworthy.
- Enable multi-factor authentication and use unique passwords.
- If you clicked: change your password, enable MFA, report it and scan your device.
